## 1. 产品最终愿景

**小钱家不是账单表格、专业财务控制台或漂亮的空壳 Dashboard；最终要成为普通用户愿意每天打开、可以长期放心使用的个人/家庭财务伙伴。**

目标体验：
- 像多邻国一样圆润、轻松、有成长反馈；角色问候、今日任务、进步、轻量地图与风险卡可作为首页设计方向，具体 UI/文案/动画仍需单独审批。
- 用户操作尽量少：直接导入真实微信、支付宝、银行卡/信用卡账单；系统完成能可靠自动处理的部分，只有真正影响财务准确性的歧义才集中提问。
- 四大基本盘始终清楚：**消费/支出、现金、资产、债务**。收入属于真实交易事实和分析要素，而不是另立第五个首页基本盘。预算、提醒、分账本和 Pro 精细功能分别融入已有基本盘。
- 看得懂“本月花了多少、现金还有多少、真正欠多少、能否覆盖近期必要支出”，同时知道哪些数字已核对、哪些只是部分信息。
- 尊重可信事实：真实发生/到账事实、用户主动设定计划、推导分析严格分层；不将未知视为零，不将预计钱视为到账，不虚构交易凑平账，不重复记账。
- 优先在 Mac 上稳定、长期、日常使用；未来 iPhone / 原生体验属于扩展愿景，不能据此声称已授权跨端同步或技术重构。

## 2. 目标用户与体验原则

- 首要对象：不愿学习专业会计、不愿维护复杂字段的日常个人财务使用者。
- 首次使用：可分批上传账单，集中确认影响财务正确性的事项；即使资料不完整仍可使用已确认部分，但不能显示虚假的“全量准确”结论。
- 日常使用：少填表、少强制流程、少弹窗；历史补账、重复导入、退款、还款等不能反复改变今天已核对的余额。
- 进阶能力：复杂分析与细分能力可选择开启，不能反过来阻碍普通用户。
- 视觉方向：多邻国式亲切、卡通、圆润和明确反馈；所有具体设计细节另行审批。

## 3. 财务模型硬边界

1. **四盘联动**：消费、现金、资产、债务分别保持真实含义；各类统计和计划共享明确数据来源。
2. **三层语义**：`FACTS / PARAMETERS / DERIVED RESULTS`，即事实、用户设定、推导结果；不得混淆。
3. **已核对当前余额保护**：历史账单导入、重分类、退款历史分析回算，不得无证据重复冲击当前已确认现金/债务。
4. **账户归属与账本隔离**：不把不同人、不同账本和不同账户的资金擅自混合。
5. **可追溯与可撤销**：保留能支撑去重、纠错、来源和恢复的必要证据；原始敏感文件默认最小化保留。
6. **无证据不猜测**：金额、交易性质、账户、时间、是否完成、分期、债权、汇率、完整性有疑问时应显式标记。
7. **保护隐私和成本**：本地优先，第三方云处理需清楚告知和显式授权；未另获 Owner 允许不得引入新增付费服务。

## 4. 本阶段产品范围与未来范围

### 当前已批准规划（不是已实现）
- A06-1～A06-9 的导入与账务原则；其中 A06-9 共有 23 个 Owner 决策，详见 `01_APPROVED_DECISIONS_REGISTER.md`。
- 真实账单格式适配：CSV、XLS/XLSX、文字型 PDF 和其他真实导出结构按具体样本逐格式验收；ZIP/多文件/多工作表；未知结构化格式可尝试识别，但不能假装正式兼容。
- 财务正确性优先：跨来源去重、账户关联、退款、分期、真实资金到账/扣款、历史统计回算、缺口提示、对账差额处理。
- 信用卡本阶段精简：可信总欠款与到期日；已出/未出、最低还款等复杂细项暂缓，避免因通用分期原则自动扩张范围。
- AA/朋友往来/报销本阶段精简：通过分账本与用户手动分类，不建立复杂自动催收/应收款系统。
- 加密 PDF/Excel 本阶段不支持直接解密；已批准的 ZIP 密码处理不意味着支持内部加密账单。

### 未来方向/待审批细节
- 图片及扫描版 PDF 的 OCR 属于后续阶段。
- 汇率参考值、统一人民币估值、汇兑损益尚待另议。
- 分账本具体规则与界面、Pro 细分能力、视觉动效实现、长期跨设备同步与 Native 迁移另行审批。
- A05 全部预算/风险精细逻辑不可因部分原则获批就视为全面通过。
- 房产相关产品规划已取消，不在当前工作范围。

## 6. 永远遵守的推进门禁

- 规划记录 ≠ 需求最终冻结；冻结需要 Owner 明确批准。
- 需求冻结 ≠ 授权 Agent 修改代码或数据。
- 可运行骨架 ≠ 已具备完整财务正确性。
- 单项 PASS ≠ 整体 PASS；模拟数据 PASS ≠ 真实数据/生产 PASS。
- 新功能测试通过 ≠ 允许替换 Runtime 或迁移正式数据库；两种生产授权仍独立。
- 修改源码的执行 Agent 不得给自己的实现作独立终审。
- 任何涉及真实财务数据、生产迁移、外部云处理、付费服务或破坏性操作都需要明确且分别授权。

## 7. 最终成功定义

用户无需终端或数据库知识，能够以轻量方式在稳定的 App 中持续管理真实财务；四盘数值可信、来源可查、未知明确、历史可核、升级可恢复；体验亲切且不会用花哨动画掩盖关键风险。只有经过逐项独立测试、整体回归、生产安全门禁和 Owner 最终接受，才可声明对应正式版本真正落地。

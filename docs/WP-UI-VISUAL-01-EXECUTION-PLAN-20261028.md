## 1. 通用冻结规则(P1–P4 共用)

**1.1 口径(B-01)**
- 固定负担 = 所选月份固定支出总额 + 必须偿还月供总额,同一笔还款不重复计入。
- 圆环中心 = 所选月份实际收入。外环 = 固定支出 ÷ 收入;内环 = 必须偿还月供 ÷ 收入;各自独立计算。
- 结构余量 = (月收入 − 固定支出 − 必须偿还月供) ÷ 月收入,只在主卡显示,不入环。
- 消费进度不再进圆环;分类卡与圆环不要求一一对应。
- 缺失数据不补零、不用旧月份数据、不用过期快照。

**1.2 收入四态(互不混用)**:缺失 / 待确认 / =0 / 为负,各自独立处理(见 §2)。收入缺失或待确认时外环同样不能计算。

**1.3 色彩与对比度**
- 品牌色 蒂芙尼蓝 `#7CC9BF`、琉璃黄 `#FBD83B` 保留,但不得独自承担必要数据边界或小字(对白 1.92:1 / 1.40:1,不达 3:1)。
- 必要图形边界用:深蓝绿 `#286D65`(对灰轨 5.17:1)。深黄 `#B87700` 仅作必要图形备选(3.70:1,不用于小字、不替代品牌黄)。
- 深珊瑚 `#C2503C` 仅为外置超额标记**候选色**,Owner 未选定,不得写进实现。
- 不用整组 opacity 表次要状态;不让每个图标带彩色底托。
- 实现阶段仍须对真实背景、边界、交互态、焦点态实测。

**1.4 字号四级封顶**:34 主数字 / 22 行金额 / 16 卡题 / 12.5 辅助。动态字体放大允许换行增高,不得锁死文字。

**1.5 布局**:`.finance-page` 生效 980px(`style.css:2710`),`.detail-page` max-width 800px(`:1652`),主列 586px。断点只用既有 760,不新造。390/760/1000 单列,1440 双列;不改页面双列、不扩大正式容器。手机主要触控区 ≥44×44 CSS px。

**1.6 文案冻结**:现网原文逐字保留 / 复用他页原话 / 新增只留 `P-` `H-` `E-` 槽位。设计注释不进界面;不自造句子;不出现「示例数据/演示/占位」;标题统一「固定支出·{实际数量}项」。

**1.7 动效(Owner 已接受为实施基线,偏离须报备)**:展开/收起 180ms、进度线 220ms、数字变化 160ms 淡入淡出、图标反馈 140ms,统一 `cubic-bezier(0.2, 0, 0, 1)`。首屏不播整页入场;仅用户操作或已确认数据变化触发;中断以最新已确认状态为准;`prefers-reduced-motion` 取消位移与进度生长(即时或 ≤100ms 透明度过渡)。付款提交前不播成功反馈,保存并回读成功后才反馈。

**1.8 图标**:项目现用 `lucide-react`,历史规范 20px/2px/currentColor,实现中混用。20px/2px 仅作统一候选起点,**未签认**;先核对项目规范,缺失才提候选尺寸;图标只在层级需要时用。不引入第二套图标库;不得宣称「原生系统控件」。

## 4. P2 固定支出页与分类进度

**范围**:D-02 标题「固定支出·{n}项」删副标题;D-03 已付行隐藏「再记一笔」;D-05 删独立提示行;D-06 简洁列表 + 细进度线、只显已付进度、未付用普通灰底不用虚线;D-07 空态仅「固定支出·0项」+「暂无固定支出」,不加插画/图标/CTA,限宽 640 居中、min-height 360。
**B-03 逐字冻结**:
- 计划=0 且已付>0:「计划 ¥0 · 已付 ¥Y · 超计划 ¥Y」,不显示比例。
- 已付>计划两行:「已付 ¥1,200 / 计划 ¥1,000」+「超计划 ¥200 · 已付/计划 120%」(百分比字段统一称「已付/计划」)。
- 计划>0 已付=0:进度 0,标签「未付」;计划=0 已付=0:不出现 `0/0` 或 `0%`;计划缺失 ≠ 计划为 0。
- 视觉封顶、数字不封顶:轨道可封顶,实际金额/比例/超额金额不得截断、归一化或改写。
- 已付低存在感纯文字,未付用主按钮「记一笔」,不做绿色徽章。
**待统一**:`待付`/`未付` 统一为「未付」(OPEN,按 Owner 签认);「导出备份」是否保留属 OPEN,不得擅自增删。
**验收证据**:五态表(计划>0 已付=0 / 计划=0 已付>0 / 已付>计划 / 计划=0 已付=0 / 计划缺失)截图 + 逐字比对。

## 6. P4 月份切换与无障碍动效

**范围**:一个共享紧凑月份控件(「本月/上月」),全部数据按所选月份重算。
**B-05 数据一致性(阻断项)**:请求携带月份标识;旧请求不得覆盖新数据;切换期间骨架屏(保持原布局,无加载文案);缺失不补零;局部错误「这一块没读出来,点这里重试」;缓存过期或切换中断不得静默沿用旧快照。
**最小验证方式**:快速连切两个月 + 人为延迟旧月份响应返回,证明旧响应不覆盖当前月份;截图或日志同时核对标题/金额/圆环/分类进度/待确认债务。
**无障碍**:图形对比度 ≥3:1,文字独立验收;状态不靠颜色单独表达;真实 DOM 关联;键盘焦点可见;可访问名称;动态字体验证。
**OPEN**:切到「上月」后「本月已付占比」措辞歧义,须在文案签认时处理,设计师/执行员不得自行换词。

## 逐项提审对象（每项 = 一个对象）

### A-FONT-001 字体
- 要解决：字体栈第一个是 `DM Sans`，但项目没有加载它（没有 `@font-face`），在手机上必然落到备选字体，不受控；中文还会混用不同字体。
- **推荐：** 改用系统字体栈 `-apple-system, "SF Pro Text", "PingFang SC", system-ui`，不引入任何字体文件。理由：你自己写的是"系统字体"；苹果的字距和字号在系统字体里已调好。代价：数字不再是 DM Sans 那种圆润感。
- 替代 1：打包 DM Sans。好处：数字风格不变。代价：增加包体积、需要许可核对、仍与 iOS 系统观感有差距。
- 替代 2：英文数字用系统字体，只有品牌「小钱家」用定制字。代价：多一套规则。
- 附带要决定：金额是否改成等宽数字（`font-variant-numeric: tabular-nums`），避免数字变化时宽度跳动。我推荐是。
- 样片：我可以在真机包里做 A/B 两版，你对比截图。**当前没有。**

### A-SHEET-001 记一笔弹层的形态
- 要解决：现在是屏幕正中的小窗，圆角 10px；你的要求里写了"底部 sheet"。
- **推荐：** 从底部升起的 sheet，顶部圆角约 16 到 20，带小拖拽条，向下拖可关闭，键盘弹出时顶住键盘。理由：拇指够得到、符合 iOS 习惯。代价：要做拖拽手势和键盘避让，**这是这批里工作量最大的一项**，真机软键盘行为我目前没有任何实测证据（状态文档里 `OPEN-F6` 同样挂着这一条）。
- 替代 1：保持居中弹窗，只把圆角、阴影、间距调得更苹果。好处：几乎零风险。代价：不满足你"底部 sheet"的要求。
- 替代 2：全屏页（push 进去）。好处：输入空间大。代价：对"3 到 5 秒记一笔"太重。
- 样片：**没有。** 需要先做可操作原型。

### A-HOME-002 首页顶部区域
- 要解决：顶部栏横排塞了品牌、月份、「记一笔」，是桌面网页结构；"记一笔"在右上角，单手够不到。
- **推荐：** 去掉品牌横栏，改成 iOS 大标题（"本月"或你定的名字），「记一笔」做成底部居中的主按钮（悬浮在安全区之上）。理由：拇指区、层级清楚。代价：品牌 logo 不再常驻首页。
- 替代 1：保留顶部栏，只把按钮放大到 44pt 以上并加上安全区。好处：改动小。代价：仍是桌面感。
- 替代 2：做底部标签栏（今天 / 记录 …）。**不建议现在做**：M1 范围只有一个页面，标签栏会引出你"不做"清单里的页面。
- 样片：**没有。**

### A-TOUCH-003 触控尺寸
- 要解决：顶部「记一笔」40px、分类按钮 38px 高且字号 12px；苹果建议可点区域至少 44pt。
- **推荐：** 所有可点元素最小 44px，分类按钮字号 14 以上。代价：分类按钮一行放不下 6 个，需要两行，页面会变长。
- 替代：保持尺寸，只加大点击热区（透明扩展）。好处：外观不变。代价：看起来仍小。
- 样片：**没有。**

### A-FEEDBACK-004 按下反馈
- 要解决：按钮按下时几乎没有反馈（`:active` 只有零星几处）。`mobile-native` 与 `apple-design` 都强调"按下立刻响应"。
- **推荐：** 所有按钮按下时缩放到 0.97，100 毫秒，松开弹回；减弱动效模式下改为轻微变暗。理由：最小改动，最大的"原生感"。代价：几乎没有。
- 替代：不做，保持静态。
- 样片：可以直接装机让你按。**没有。**

### A-MATERIAL-005 材质与分隔
- 要解决：顶部栏已有半透明和模糊（`backdrop-filter: blur(12px)`），但配色是米色实底，没有"内容在栏下滚动"的层次。
- **推荐：** 保持现有半透明顶栏，去掉底边的实线，改为滚动时才出现的淡边。代价：需要监听滚动。
- 替代：不动。
- 样片：**没有。**

### A-DARK-006 深色模式
- 要解决：完全没有深色模式支持；用户把手机设成深色时，App 仍是浅色，状态栏文字可能和背景对比不对。
- **推荐：** M1 先不做深色，保证状态栏和背景在浅色下正确。理由：做深色要重新过一遍所有颜色，属于大工作。**待决策。**
- 替代：现在就做深色。代价：大量颜色逐项审批。
- 样片：无。

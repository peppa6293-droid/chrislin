# 小钱家体验改版 · UI 与动画设计稿

- 版本：V1.0
- 日期：2026-10-23
- 适用平台：macOS 桌面窗口，React + TypeScript + 现有 `v2-*` CSS + `lucide-react`
- 设计角色：审美决策者
- 实现原则：执行者按本稿逐条实现；本稿只规定视觉表达、布局、交互反馈和文案，不改变数据口径、账本契约或功能范围。

## 1. 设计原则

### 1.1 风格定位

「圆润、明快、有完成感的个人财务空间」。参考多邻国的动作反馈和进度感，但不复制其品牌资产。视觉关键词对应到实现值：

- 大面积暖白背景，青绿色作为主行动色，珊瑚色作为超支/警示色，黄色作为庆祝色。
- 卡片使用 20px 圆角，按钮使用 12px 圆角；禁止像素边框、像素字体、复古 CRT、硬直角仪表盘。
- 一屏只回答一个问题；结论先于数字；金额是证据，不是标题。
- 图形优先：进度条、阶段点、插画式图形、短句；不堆叠 10 个指标。
- 动效只服务于「刚刚完成了什么」和「现在该做什么」，不做持续漂浮、背景粒子或无意义循环。

### 1.2 明确不做

- 不改收入、固定支出、月供、本月已花、消费目标、安全垫、债务等数据定义。
- 不把固定支出支付写入弹性消费账；不把信用卡还款重复算作消费。
- 不把计划还款显示成实还；不隐藏「计划计入」与「实际还款」的区别。
- 不使用原生 `datetime-local`；日期只选业务日期，不出现时间输入。
- 不把 `PixelWorld`、像素庆祝、像素字体或旧像素插画搬入新界面。
- 不使用大号红色数字作为唯一反馈；超支需要解释和下一步。

## 5. 记账反馈三件套

反馈层共用 `v2-feedback-stage`，宽 560px、高 420px，居中 Sheet。保存动作完成且读回确认成功后才触发；失败不庆祝，只显示错误与重试。

### 5.1 记完一笔

构图：上方 72px 彩色圆形图标区；中间标题「记好了！」；副文案「这笔 ¥49.90 已放进今天的账本」；下方 160px 进度条/类别插画；底部主按钮「继续」和次按钮「查看今天」。

动画：触发后 0–100ms 图标圆从 `scale(.7)` 到 `1`，360ms `--v2-ease-bounce`；100–780ms 8 个 6px 圆点从中心向外 `translate` 16–44px、opacity 1→0，分别延迟 20ms；160–680ms 进度条由旧值增至新值，`--v2-ease-emphasized`；标题在 180ms 后淡入 220ms。粒子不可遮挡文字，禁止无限循环。

| 状态 | 视觉 | 文案 |
|---|---|---|
| 保存中 | 图标 24px 旋转仅限 loading，标题「正在记下」 | 主按钮 disabled |
| 成功 | teal/yellow、CheckCircle2、一次性庆祝 | 「记好了！」 |
| 读回失败 | coral 图标、无粒子 | 「还没确认保存成功」+「再试一次」 |
| 表单错误 | 回到字段，字段下方 12px coral 文案 | 「请补充金额/日期」 |
| 关闭 | 无反馈动画 | 不丢失未提交数据，按现有确认规则处理 |

### 5.2 记完一天

触发条件沿用现有业务判断：当天完成记录后由产品状态决定是否展示，不由 UI 自行推断。构图为 3 段横向轨道：`今天`、`昨天`、`连续`；当前点 44px teal 圆，已完成点 20px teal，未完成点 20px line。

文案：标题「今天的账，记完了」；连续时「已经连续记了 N 天」；无连续时「今天是一个很好的开始」。按钮「看看今天」。

| 状态 | 视觉 | 动效 |
|---|---|---|
| 首次完成 | 当前点从 0→44px，填充 teal | 520ms，bounce |
| 连击增加 | 新点点亮，旧点保持 | 680ms，点位依次延迟 100ms |
| 中断后重新开始 | 不用红色，不显示失败 | 文案「今天重新开始」；360ms fade |
| 无当天数据 | 空轨道 | 「记一笔，今天就会亮起来」 |

### 5.3 记完一月：月度小结页

不是报表。全屏 Sheet，最大宽度 760px，分页式 3 张 PPT 卡，每次只展示一张；底部「上一张 / 下一张 / 完成」。

1. **开场页**：插画 `Sprout` +「这个月，你把钱照顾得怎么样？」
2. **行为页**：用 3 个图形表达记录天数、最常见类别、最高支出日；不使用 3 列大数字表。
3. **结论页**：依据已有数据口径给一句结论，如「本月消费在目标内」「下个月可以提前留出还款的钱」；下方最多 2 个行动按钮。

每页状态：

| 状态 | 规格 |
|---|---|
| 进入 | 页面整体 `opacity 0→1`，插画 `translateY(20px)→0`，500ms，emphasized |
| 翻页 | 当前页 `translateX(-24px), opacity 1→0` 220ms；下一页 `translateX(24px)→0` 360ms |
| 完成 | 最后一页按钮出现 Check，黄色圆点 6 个从下向上 680ms |
| 无数据 | 只显示「这个月还没有足够记录」，不给虚构结论；按钮「去记一笔」 |

## 9. 动画专项与 reduced-motion

### 9.1 全局降级规则

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
    scroll-behavior: auto !important;
  }
}
```

同时在 React 层通过 `matchMedia('(prefers-reduced-motion: reduce)')` 得到 `reducedMotion`：不渲染粒子、不播放弹跳/翻页/数字递增；保留最终颜色、进度、完成图标和完成文案。完成感必须仍然存在。

### 9.2 逐条对照

| 动效 | 正常 | reduced-motion |
|---|---|---|
| 记一笔庆祝 | 圆形弹跳 360ms + 粒子 680ms + 进度 520ms | 立即显示 CheckCircle2、最终进度和「记好了！」 |
| 一天完成 | 点位依次点亮 680ms | 所有已完成点同时静态点亮 |
| 一月小结 | 页面滑动翻页 220/360ms | 直接替换内容，不滑动；保留页码变化 |
| 首页进度 | 520ms 宽度增长 | 立即到最终宽度 |
| 建立余地完成 | Sprout bounce 680ms | 立即显示完成插画、黄色进度和徽章 |
| 弹层打开 | scale + opacity 220ms | 立即出现，不改变布局 |
| 错误反馈 | 微缩放/摇动 | 只显示 coral 边框、错误文本和图标 |

## 3. 六组剩余阻断项及 Owner 确认要求

### B-01：圆环准确分段口径（必须回答）

请明确圆环本身的分段组成，三选一或给出其他精确定义：

- A：`固定支出 + 必须偿还月供 + 非负结构余量 = 月收入`；
- B：仅表示固定支出/必须偿还月供的分类构成；
- C：其他：________。

同时确认：

1. 固定支出和必须偿还月供是否在圆环上分别成段；
2. 分类卡是否与圆环分段一一对应；
3. 圆环中心是否始终显示所选月份月收入；
4. 结构余量是否只在非负时绘制，还是负余量也须有独立视觉表达。

### B-02：圆环特殊状态（必须逐项确认）

| 状态 | 必须确认的规则 |
|---|---|
| 月收入 = 0 | 是否不绘制圆环；是否隐藏所有百分比；保留哪一句零收入文案 |
| 固定负担 = 月收入 | 是否整环为负担、余量为 0；临界色和标签如何显示 |
| 固定负担 > 月收入 | 超出部分如何绘制；是否使用斜纹/珊瑚色；白线与超出段如何排列；是否显示超出金额 |
| 待确认债务 | 是否阻断圆环/评级；确认前不得使用旧快照显示金额或比例 |

硬性验收要求：不得用缩放、归一化或截断掩盖实际超支；不得除零；不得把超载显示成正常 100%。

### B-03：固定支出分类进度边界（必须逐项确认）

请确认：

1. 分类计划金额 >0、已付金额 =0：进度线是否为 0，标签是否只显示「未付」；
2. 分类计划金额 >0、已付金额 >计划金额：是否允许进度线超过 100%；超额部分如何标识；实际已付金额和超额金额是否同时显示；
3. 分类计划金额 =0、已付金额 >0：不得计算普通百分比，采用何种文案/标记；
4. 已付金额不得静默截断、归一化或改写为计划金额。

### B-04：负收入归属（必须回答）

当前公式只在 `月收入 > 0` 时进入五档评级；请确认负收入：

- A：业务上不可能，输入层必须阻止并进入错误态；
- B：作为异常状态，单独定义文案和视觉规则；
- C：沿用零收入处理；
- D：其他：________。

若选择 B 或 D，必须提供逐字文案、圆环规则、百分比规则和验收证据要求。

### B-05：本月/上月切换数据规则（必须确认）

切换月份后，请确认以下内容是否全部按所选月份重新计算：

- 标题及结论句；
- 圆环中心收入；
- 固定支出、必须偿还月供和分类金额；
- 已付/计划比例；
- 待确认债务状态；
- 超载金额及边界色。

硬性规则：不得沿用本月数据、旧首页快照或过期缓存；所选月份数据不完整时必须有明确状态，不得静默补值。

### B-06：D-08 动效与 D-09 图标规格（必须细化）

#### D-08 动效

请补齐：

- 动效对象：展开/收起、条形生长、数字变化、图标反馈分别适用于哪些组件；
- 触发条件：首次进入、数据更新、用户操作分别如何触发；
- 时长与缓动：各动效具体时长、缓动方式；
- 状态规则：取消、错误、重复点击、中断时如何处理；
- 可访问性：`prefers-reduced-motion` 下是否关闭或降级。

范围限制：不得扩展为复杂动画系统；未确认的动效不得进入实现。

#### D-09 图标

请补齐：

- 图标类型及使用位置；
- 尺寸与有效绘制区域；
- 描边/填充、颜色和状态色；
- 圆角底托是否保留及规格；
- 正常、已付、未付、错误、空态、展开/收起状态；
- 文本替代、键盘焦点和非颜色识别规则；
- 是否接受“Apple App 系统原生风格”作为方向，而不作为单独实现规格。

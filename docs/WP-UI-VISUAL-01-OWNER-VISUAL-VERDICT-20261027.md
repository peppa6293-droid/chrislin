## 0. 冻结链路的四条硬规则

1. 设计侧本轮只改**版式、间距、颜色、状态**，一个字的现网文案都不改。
2. 稿面文字只允许「原样 / 复用 / 新增槽位」三类；新增一律写 `P-xx` / `H-xx` / `E-xx` 编号。
3. 槽位标记必须是**设计注释层**（灰底、虚线框、图注说明「文案槽位，非产品文案」），不得做成看起来像真文案的灰字。
4. 界面上不得出现「示例数据 / 演示 / 占位」；设计注释只存在于 HTML 源与图注，不进 UI。

## 3. 一处必须回填决策书的宽度护栏

**生效宽度是 980，不是 860。** `src/style.css` 里 `.finance-page` 出现两次：`:1762` 是 `max-width: 860px`，`:2710` 是 `max-width: 980px`，后者在文件后段覆盖前者。我上一轮引 860 是引了被覆盖的前一条，**该论据撤回**。

但结论不变、而且更强：980 减去右列 372 与 22 gap，主列只剩 **586px**，双列在默认宽度下根本不成立。

因此 §1.3「980 → 1120」必须带断点，否则在 1000px 窗口会出现横向滚动：

- 视口 ≥ 1180：页面 1120，双列（右列 300，gap 22）；
- 980 ≤ 视口 < 1180：页面撑满可用宽，单列，环形 + 分类小计并排落到列表下方；
- 760 ≤ 视口 < 980：单列，环形与分类小计上下叠；
- < 760：沿用现有 `@media (max-width:760px)` 断点（`style.css:1156/2077/2164` 已有三处）。

760 不是随手取的数：它是全仓既有断点。1120 双列只作为 1440 展示稿成立。

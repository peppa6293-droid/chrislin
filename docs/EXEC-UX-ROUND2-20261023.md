## 2 WP-A 设计稿实现（审美项，照稿逐条）

按稿 §10.4 六步顺序落地：

1. `v2-tokens.css`（稿 §2 全部变量）、金额格式统一（`money-format.ts` 输出 `¥ + 千分位 + 两位小数`）、通用卡片/按钮/进度条/徽章/空态（稿 §3 状态表）。
2. 首页两卡（稿 §4）：`V2StructureCard` + `V2MonthlySpendCard`，替换 `V2HomeSurface` 现有混排卡；数据读取沿用现役首页口径，**UI 层不重算金额**。
3. 记一笔反馈（稿 §5.1）：`V2FeedbackStage`，接现役 `saveExpense` 保存+读回成功后触发；失败只报错不庆祝。
4. 日历式日期选择器（稿 §6）：`V2CalendarPicker` 替换原生日期输入；只选业务日期，不出现时间输入；键盘左右上下/Enter/Escape 可用。
5. 建立余地页（稿 §7）：`V2SavingsRoomPage`，页面标题定「建立余地」，副标题「给未来留一点空间」；接通导航入口。

### 2.2 反馈触发口径（勘误二的落点，属功能口径不属审美）

- **记完一天**：当天任意一笔保存成功后弹一次（每天最多一次）；「连续 N 天」= 按业务日期去重后的连续记录天数，**只读推导，不写库、不改口径**。中断后重新开始照稿 §5.2 不用红色。
- **记完一月**：当月最后一笔保存成功后自动弹一次；另在进度页给「看本月小结」手动入口。小结三页内容只用现有数据口径，无数据时只显示「这个月还没有足够记录」，不给虚构结论。

## 3 WP-B 流水页真实翻月

- `LedgerPage.tsx` 现按 `asOfDate.slice(0, 7)` 硬绑会话月份。改为**独立月份状态**（默认当月），提供「上一月 / 下一月」+ 月份显示；只到 `YYYY-MM` 粒度，不做日历月视图。
- 样式按稿 §3 通用组件：图标按钮 `ChevronLeft` / `ChevronRight`（36×36，lucide 18px，hover `--v2-teal-soft`），月份徽章 pill 24px 高；**不得自行发挥样式**。
- `__WP03_PREVIEW_BUILD__` 保持 `"false"`，**禁止靠翻开关冒充翻月**。
- 翻月后归类、编辑、删除、导出在任意月份照常可用；导出仍是全量导出，不随月份变。
- 翻月不改变会话基准日；还款/固定支出等页面的日期语义不受影响。

## 4 WP-C 补分类、词表、全量归类

1. **新增 5 个 V2 分类**（数据行，走应用层服务/界面写入，禁直插 SQL）：医疗、居住、水电、保险、教育；字段对齐现有 6 分类：`builtin=1, active=1, adjustable=1, overspending_alert=0, savings_related=0`；icon/color 见 §2.1。**不改 schema**，`user_version` 保持 8。
2. **词表扩充**（`src/model/import-rules.ts` 只加商户关键词，不动置信度机制、阈值、既有别名）：闲鱼→购物；中国移动/联通/电信/宽带→水电；医院/药房/诊所/体检→医疗；链家/自如/贝壳/物业→居住；平安/众安/太保/人保→保险；新东方/学而思/书店/培训→教育。以只读模拟覆盖率报告为准再定终稿，报告随回执。
3. **全量归类执行**：先只读模拟出建议分布与「其他」剩余 → 界面「自动归类」逐月执行（配合翻月）→ 每次确认断言**总额/笔数不变**；只改 `expenses.category_id`。
4. 归类属显示归类，**不触碰 V1 镜像**（D-01）、不触碰月度模型。上轮已改的 17 笔美团→餐饮不回滚。
